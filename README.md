# Web3 Crowdfunding

[![Contracts CI](https://github.com/Ilja-Prihach/web3-crowdfund/actions/workflows/contracts.yml/badge.svg?branch=main)](https://github.com/Ilja-Prihach/web3-crowdfund/actions/workflows/contracts.yml)

Decentralized crowdfunding platform where campaign creators can raise ETH transparently through smart contracts.

## Project structure

- `contracts/` — Solidity smart contracts, tests, and deployment scripts.
- `frontend/` — the web application for campaign creators and contributors.
- `docs/` — architecture and project decisions ([CI](docs/ci.md)).
