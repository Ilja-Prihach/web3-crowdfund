# Hero-иллюстрация

`hero.webp` — авторская демонстрационная иллюстрация распределённой blockchain-инфраструктуры. Она не изображает реальную кампанию, UI, финансовые показатели или существующую сеть узлов.

Исходник сгенерирован встроенным imagegen 29 октября 2026 года. Визуальный бриф: тёплый editorial-образ публичного программируемого реестра с равноправными вычислительными узлами, транзакционными линиями и прозрачными слоями данных; без текста, логотипов, монет, Ethereum-символа, неона и вымышленных метрик.

Несжатый PNG не хранится в Git. Проектная версия имеет размер 1536×1024 px и оптимизирована в WebP с quality 76:

```sh
npm run optimize:images -- <source.png> src/widgets/HeroSection/assets/hero.webp 1600 76
```

После каждой повторной конвертации проверяйте изображение визуально и подтверждайте, что размер файла не превышает 180 KB.
